# Apex Radiance 2.13.0

2026-10-12 · [v2.13.0](https://github.com/loinyx/Sims3-ApexRadiance/releases/tag/v2.13.0) · ApexRadiance.asi

## Highlights

Keyboard shortcuts for presets

## New features

- **Preset shortcuts:** right-click any preset, personal or built-in, to assign a key combination; letters, digits and Space need Ctrl or Alt, so typing names never applies a preset. Pressing it applies the whole preset, with the usual Undo. A tag on the row shows the keys.

## Changes

- Keyboard shortcuts now apply presets instead of single filters. Shortcuts assigned to filters in 2.11.0 to 2.12.1 are no longer used; assign them to a preset instead.
- Shortcuts are saved with your menu preferences, not inside preset files, so exported presets do not carry them.

## Known limitations

- The first key of a multiple-key combination may reach the game before the combination is recognised.

## Upgrade notes

Close the game and launcher, then replace **ApexRadiance.asi** in **The Sims 3\Game\Bin\**. Existing settings and presets remain compatible. No additional DLL is required.
