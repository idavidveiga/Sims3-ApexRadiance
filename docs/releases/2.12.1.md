# Apex Radiance 2.12.1

2026-10-12 · Reviewed release · ApexRadiance.asi

## Highlights

More consistent outdoor walls, fences and gates

## New features

No new controls or companion files

## Changes

- Exterior walls respond a little faster to lighting changes
- Covered deferred wall updates are skipped when a newer lighting generation already includes them

## Fixes

- Fence lighting better follows the position of lamps
- Gates receive lighting more consistent with fences
- Valid fence groups use spatial lamp lighting rather than keeping shared vertex lamp light as a brightness floor

## Known limitations

- Missing spatial data keeps the native fallback for fence groups
- This update does not promise instantaneous lighting or a measured FPS increase
- Gameplay confirmation covers the final development candidate, not the rebuilt release artifact
- The public x86 build and native D3D9 fixtures pass; all 21 changelog language tables pass offline validation
- The maintainer verified the version menu in the public build; the final rebuild changes only the selected release wording
- An isolated delay in indoor cross-story lighting resolved without a code change; its capture is retained for follow-up

## Upgrade notes

Close the game and launcher, then replace **ApexRadiance.asi** in **The Sims 3\Game\Bin\**. Existing settings and presets remain compatible. No additional DLL is required
